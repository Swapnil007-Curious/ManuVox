# Model selection for the web demo

Generated by `scripts/model_selection.py report`.

- Accuracy: signer-independent test split, from `results/tables/selection/` (`scripts/final_eval.py`); single models are the mean ± sd over seeds 0-2, ensembles average the three seeds' logits in one ONNX file.
- Latency: one classifier call (input 1 x 32 x frame_dim) in Chrome 157.0.8103.52 on the i3-1115G4 laptop, onnxruntime-web wasm SIMD, 1 thread, 20 warm-up and 200 timed calls (`web/scripts/benchmark.mjs`); single models use the seed-0 file.
- Rule (fixed before measuring): the highest test top-1 with p95 < 60 ms and a file under 10 MB (the limit for a committed model.onnx). Validation top-1 ranks the candidates the same way (`results/tables/selection/val_summary.csv`).
- fp16 rows repeat the fp32 accuracy: the test split was only evaluated in fp32, and the exported fp16 file's val top-1 equals fp32's (`web/public/model/meta.json`, `variant_selection`).
- Latency is the classifier alone; next to live tracking on the same laptop the shipped file took p50 18.6 / p95 27.2 ms per segment (`results/perf/tracking_gpu.json`).
