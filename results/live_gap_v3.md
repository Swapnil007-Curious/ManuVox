# Live-gap evaluation v2

Generated by `scripts/live_gap.py report --configs experiments/live_gap_v2.json` from the runs
under `results/live_gap_v2/`. The 10-clip pilot is in `results/live_gap.md`.

## Setup

- Clips: 50 webcam recordings in `test_clips_v2/` (25 signs x 2 takes, one
  signer, the author), recorded unmirrored at 1280 x 720 and about 15 fps; converted with
  `scripts/prepare_live_clips.py --camera` to 640 x 360 .y4m at the recording's frame rate.
  Both pipelines read the same frames. No clip is a duplicate of another (SHA-256).
- Python + Holistic and Browser + Tasks: as in the pilot (`results/live_gap.md`); the browser
  runs in the installed Chrome on the target laptop with the GPU delegate, one browser per clip
  running every config in a seeded random order (`web/scripts/live-gap.mjs --per-clip`).
- Scoring: the clip's prediction is the mean of its classified segments' probability vectors; a clip without a classified segment counts as wrong.
- Nothing was tuned on these clips (thresholds and temperature from val). Analysis, fixed
  before any run (`experiments/live_gap_v2.json`, `analysis`):
  - unit: clip (n = 50: 25 signs x 2 takes); the two takes of a sign are not independent, which the bootstrap over clips does not model
  - primary metrics: clip top-1 and clip top-3
  - browser repeats: each browser config runs 3 times; a clip's score is its mean over the runs
  - confidence intervals: percentile bootstrap over clips, 10000 resamples, seed 0
  - comparisons: v3_final - v2_final per pipeline on clip top-1, paired over clips (sign-flip test), reported with the v2-vs-v3 comparisons on the asl-signs and ASL Citizen test splits in one Holm family (scripts/compare_v3.py); the sign-level interval is a sensitivity analysis
  - test: two-sided paired sign-flip permutation test on the per-clip score differences (exact enumeration up to 20 non-zero differences, otherwise 100000 random sign flips, seed 0)
  - multiplicity: Holm correction over all comparisons of one pipeline and one metric, alpha = 0.05
  - difference intervals: paired percentile bootstrap over clips, 10000 resamples, seed 0
